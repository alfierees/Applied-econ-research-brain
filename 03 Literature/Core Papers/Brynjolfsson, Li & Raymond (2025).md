# Brynjolfsson, Li & Raymond (2025): Generative AI at Work

| | |
|---|---|
| **Question** | Does a generative AI assistant raise worker productivity, and for whom? |
| **Data** | 5,172 customer-support agents at a large US software firm |
| **Method** | Staggered rollout of an AI assistant, DiD |
| **Main finding** | Issues resolved per hour up ~15% on average; largest gains for less experienced, lower-skilled agents |
| **How we use it** | Micro evidence for the productivity side; novice gains motivate the age split |
