# Microsoft AI Applicability (Tomlinson et al., 2025)

| | |
|---|---|
| **Owner** | Microsoft Research |
| **Data** | 200k Bing Copilot conversations, US, Jan-Sep 2024 |
| **What it measures** | AI applicability score per occupation from usage frequency, success and scope |
| **Most exposed** | Media and communication, sales reps, information clerks, mathematical science |
| **Least exposed** | Forest workers, plant operators, grounds maintenance, home health aides |
| **Platform bias** | Search-style consumer tool; travel jobs rank oddly high. Correlates r = 0.73 with Eloundou |
