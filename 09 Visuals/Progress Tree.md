# Progress Tree

> [!tip] How to update
> Open [[Progress Tree.excalidraw]]. Select a box and change its background colour: green = done, yellow = in progress, grey = to do. Add a finding by copying a box under **Findings** (Alt/Option + drag duplicates it) and typing the result, e.g. "US: beta = -0.04".
