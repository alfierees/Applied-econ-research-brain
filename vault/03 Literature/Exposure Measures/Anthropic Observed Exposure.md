# Anthropic Observed Exposure (Massenkoff & McCrory, 2026)

| | |
|---|---|
| **Owner** | Anthropic |
| **Data** | Claude usage (Economic Index, Aug + Nov 2025) combined with Eloundou capability ratings; ~800 O*NET occupations |
| **What it measures** | Share of an occupation's tasks that Claude is actually used for, weighting automated use more |
| **Most exposed** | Computer programmers (~75%), customer service reps, data entry keyers (~67%), financial analysts |
| **Least exposed** | Cooks, mechanics, lifeguards, bartenders; ~30% of workers at zero |
| **Platform bias** | Claude skews to coding (about a third of traffic is computer and maths), so software jobs may look extra exposed |
| **Access** | Check whether occupation-level scores are downloadable from the Economic Index release |
