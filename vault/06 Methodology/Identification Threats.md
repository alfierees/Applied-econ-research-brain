# Identification threats

| Threat | Example | Our response |
|---|---|---|
| Omitted shocks | Rate rises, 2023 tech slowdown hit exposed sectors | Triple difference with occupation × quarter FE; drop high-tech robustness; event-study pre-trends |
| Pre-trends | Exposed postings fell before ChatGPT (Iscenko & Millet) | Event study 2019-2022; joint pre-trend F-test |
| Measurement | Exposure from vendor usage data | Several measures side by side; Felten tool-agnostic |
| COVID | 2020-21 reshuffled occupations before ChatGPT | Drop or dummy 2020Q2 to 2021Q2; show full event study |
| Code break | CPS moved to 2018 Census occupation codes in 2020 | IPUMS harmonised codes or crosswalk |
| Aggregation | Broad groups mix exposed and safe jobs | ~500 detailed CPS occupations |
| Spillovers | Control jobs also use AI | β is a lower bound |
| Control group | Controls hit by their own shocks | Check control trends; exclude if broken |
