# Current Population Survey (IPUMS)

| | |
|---|---|
| **Producer** | Census Bureau / BLS |
| **Frequency** | Monthly, ~60,000 households |
| **Covers** | Employment, ~500 occupations, industry, age, sex, education, earnings (ORG) |
| **Detail** | Census occupation codes; crosswalk to SOC |
| **Access** | Free IPUMS account |
| **We use it for** | Design A outcomes, splits |
